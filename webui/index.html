What this is

Configuration-as-Code pipeline for standard SAP customizing. Reads a business Template (customer variables + config steps), validates it against JSON Schema, resolves dependencies, diffs against current SAP state (Plan mode) and — only after your per-item approval — executes with a state machine: retry → read-back verify → human queue.

Guarantees (design doc)
  • Never connects to a real system from this machine.
  • No direct SAP DB writes anywhere in the code base.
  • Plan mode is read-only; Apply runs only against the built-in mock SAP.
  • Every step: screen actions + status message + screenshot evidence + read-back compare.
  • Overwrite / human_approval steps go to the human queue unless you tick them.
