標準 SAP カスタマイズ（OB13 / OB29 / OBY6 / OX02 / OX10 など）をテンプレート（YAML）として コード化し、検証 → Plan（読み取り専用の差分） → 人による per-item 承認 → Apply（状態機械） → 読み戻し検証 → 証跡とレポート の順に流すパイプラインです。Phase 1 の実行先は in-process の Mock SAP GUI だけで、実 SAP へは接続しません。
